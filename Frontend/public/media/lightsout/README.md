# Geräusche für Lights Out

Geladen von `src/pages/LightsOut/audio.js` (Ordner `sfx/`). Fehlt eine Datei oder kann der Browser sie nicht
abspielen, springt der im Code erzeugte Ersatzton ein — nichts hier ist Pflicht.

- **Schritte** (`step_tile_*`, `step_grass_*`, `step_wood_*`, `step_gravel_*`): Kenney „Impact Sounds“ 1.0,
  **CC0** (kenney.nl). Umbenannt: concrete → tile, snow → gravel (klingt als Knirschen auf Kies).
- **Kreaturenlaute** (alle übrigen Dateien): „80 CC0 creature SFX“ von rubberduck, **CC0**
  (opengameart.org/content/80-cc0-creature-sfx). Unverändert; tiefer und langsamer gemacht werden sie erst
  beim Abspielen (Abspieltempo 0,5–0,9, dazu Hall).
